# Souzaiosoficial EXTERNAL

Projeto migrado sobre a base atualizada do `projeto novo.zip`, com a interface, personalização, ativação por key e recursos do `original.zip` reintegrados.

Consulte [`MIGRATION_NOTES.md`](MIGRATION_NOTES.md) para o que foi migrado, limites de compatibilidade e o procedimento para gerar o IPA unsigned pelo GitHub Actions.

A política de compatibilidade foi mantida conforme declarada na base recebida: iOS 26.0–26.7.2 e iOS 27.0–27.2. Isso não garante versões posteriores.
